画像と2カラム

単体の画像・画像の横並び・本文と画像の2カラムの部品です。

関連ページ公開サイト画面の骨組み

c-figure — 単体の画像

クラス：c-figure

見本

コードを表示コピーしました
<figure class="c-figure">
  <img src="assets/placeholder.svg" alt="ダミー画像">
  <figcaption>説明（13px・--ink-soft）</figcaption>
</figure>

データの書き方: { "type": "image", "src": "services/xxx.webp", "alt": "…", "caption": "…" }

  • 角丸16px（--radius-md）。幅は100%
  • alt は必須。装飾目的の画像は置かない（現在すべて内容を持つ画像）

アクセシビリティ

  • img に内容が分かる alt。飾りなら alt=""
  • 説明は figcaption

c-figure-group — 画像の横並び

クラス：c-figure-group

見本

コードを表示コピーしました
<div class="c-figure-group"><figure class="c-figure"><img src="assets/placeholder.svg" alt="ダミー画像"><figcaption>ダミーテキストA</figcaption></figure><figure class="c-figure"><img src="assets/placeholder.svg" alt="ダミー画像"><figcaption>ダミーテキストB</figcaption></figure></div>

データの書き方: { "type": "images", "items": [ … ] }

  • 2列固定。SP（≤620px）では縦積み
  • 3枚以上を並べない（2列のため半端になる）

アクセシビリティ

  • 1枚ずつ figure と alt を付ける

c-media — 本文と画像の2カラム

クラス：c-media

見本

ダミーテキストA。本文のブロックが入ります。

コードを表示コピーしました
<div class="c-media c-media--right">
  <div class="c-media__body"><p>ダミーテキストA。本文のブロックが入ります。</p></div>
  <figure class="c-media__fig"><img src="assets/placeholder.svg" alt="ダミー画像"><figcaption>ダミーテキストB</figcaption></figure>
</div>

データの書き方

JSON

コードを表示コピーしました
{ "type": "media", "side": "right", "width": "narrow",
  "image": { "src": "…", "alt": "…", "caption": "…" },
  "blocks": [ … ] }
キー効果
side画像を置く側（既定 right）
width: "narrow"画像カラムを25%にする（既定は38%）

実装上の注意

  • ソース順は「本文 → 画像」。SPでは order: -1 で画像を先頭に上げる （何の話か先に伝わるように）
  • ≤980px で1カラムになる。narrow のときは画像の最大幅260px

アクセシビリティ

  • ソースは本文が先・画像が後（スマホでは CSS で画像を上に並べ替えるだけ）なので、読み上げは本文→画像の順になる

c-media--narrow — 画像を細くする

クラス：c-media--narrow

見本

ダミーテキストA。本文のブロックが入ります。画像の幅を細く（25%）します。

コードを表示コピーしました
<div class="c-media c-media--right c-media--narrow"><div class="c-media__body"><p>ダミーテキストA。本文のブロックが入ります。画像の幅を細く（25%）します。</p></div><figure class="c-figure"><img src="assets/placeholder.svg" alt="ダミー画像"></figure></div>

CSS

コードを表示コピーしました
.c-media--narrow { --media-w: 25%; }
@media (max-width: 980px) { .c-media--narrow .c-media__fig { max-width: 260px; } }

画像の列を25%幅にする。図版が小さくてよいとき、本文の行長を稼ぐために使う。

SPで1カラムになったときは max-width: 260px。 画像だけが画面幅いっぱいに伸びるのを防ぐ。

c-media--right と併用できる（画像を右に置いて細くする）。

画像を追加するときの手順

  1. 必ずWebPに変換する（assets/ 配下）。6.1MB → 1.0MB の実績（-84%）
  2. ロゴ・図版のようなフラットな画像はロスレスで変換する

コマンド

コードを表示コピーしました
cwebp -lossless -z 9 input.png -o output.webp

通常の変換だとPNGより大きくなることがある（payments_list.webp が該当）

  1. 変換元は残さない（別の場所に退避する）
