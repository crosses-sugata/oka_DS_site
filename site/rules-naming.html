命名規則

クラス名の付け方（c- / l- / p- / u- / a- / t-・BEM）の決まりです。

関連ページ禁止パターンマークアップ契約

接頭辞で層を分ける

クラス名の頭文字で「どこで使う部品か」を分ける。AI にも人にも、再利用してよいものとそうでないものが名前だけで分かるようにするため。

接頭辞意味使う場所
c-共通部品公開サイトと管理画面の両方。複数の場所で使う部品は必ずここに置く
l-レイアウト（骨格）ページの幅・区切り（l-wrap・l-section）
p-ページ固有トップページだけ。ほかのページで使い回さない
u-ユーティリティ5つだけ（u-nowrap・u-num・u-reveal・u-br-sp・u-visually-hidden）。増やさない
a-管理画面だけの部品骨格・サイドメニュー・状態バッジ・行の操作・本文の編集ツールなど。公開サイトにもある役割の部品を a- で作り直さない
t-院内ツールだけの部品院内ツール（紹介状 作成ツールなど）だけ。ヘッダー・⋮ のメニュー・紙の上の入力欄など、ほかに置き場の無いものだけ（css/tool.css。2026-11-03 追加）。公開サイトや管理画面にもある役割の部品を t- で作り直さない
is- / has-状態JS や状態で付け外しする。必ずブロックと一緒に使う

p- を2ページ目で使いたくなったら、それは c- にすべきもの。判断は依頼者に確認する。

BEMを使う

c-card            ブロック
c-card__title     要素（__）
c-card--priced    派生（--）
c-card.is-active  状態（単独では使わない）
  • 要素の入れ子は1段まで。c-card__head__title は作らない
  • 状態クラスは必ずブロックと併用する。.is-active 単独にスタイルを当てない（公開サイトと管理画面で衝突する）
  • 新しいクラスは CSS に定義してから使う（scripts/check_rules.py が、HTML の class が CSS に実在するかを調べる）

名前を変えるときの注意

ID はクラスとは別に扱う

site-header・mobile-nav・nav-toggle・floating-top（js/site.js）と、a-side・drawer-toggle・drawer-scrim・drawer-close（js/admin.js）は JS が getElementById で探す。クラス名の置き換えに巻き込まない。変えると、メニューやドロワーが動かなくなる。

状態クラスは JS と CSS の両方を直す

CSS だけ is-in に変えて JS が旧名のまま残ると、u-reveal がずっと見えないままになる。JS が付ける状態クラスと、CSS が待つ状態クラスがそろっているかを必ず確かめる。

1語のクラス名は class="…" の中だけで置き換える

note・lead・open などは、JSON のキーや型の名前にも同じ綴りで出てくる。コード全体を単語で置き換えると、データの定義まで壊す。

確かめるのは出力された HTML

ソースの目で見た確認や一括置換では漏れる。置き換えの前後で出力された HTML を比べ、構造が同じかを見る。
