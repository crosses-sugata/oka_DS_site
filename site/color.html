色

色は プリミティブ（色そのもの）→ セマンティック（役割）の2層 で管理しています。CSS から使うのは セマンティックだけ です。

プリミティブカラー

値は色の定義の HEX どおりです。ただし出どころが「公開サイト」のものは、公開サイトの実装の値で上書きしています。rose-50 の -rgb 版は HEX に合わせて 255, 249, 248 にしています。

各色は 50 刻みで 1000 までの20段です。出どころが「生成」の段は、隣り合う2色のちょうど中間（1000 は 950 と黒の中間）で作ったものです。今ある値は変えていません。white は 0 の1色だけです。

半透明で使う -rgb 版

半透明が必要な箇所は rgba(var(--…-rgb), .32) の形で書きます。HEX や rgb() を直接書くと check_colors.py が止めます（Phase 3 で用意）。UI ではセマンティックの --bg-rgb・--wine-rgb・--shadow-ink-rgb を使います。

トークン値色（不透明 / .32）
--rose-50-rgb255, 249, 248
--rose-500-rgb251, 78, 118
--mauve-950-rgb46, 36, 48
--wine-rgb251, 78, 118
--bg-rgb255, 249, 248
--shadow-ink-rgb46, 36, 48

セマンティックカラー

「白との比」は白い背景に置いたときのコントラスト比です。文字は 4.5:1 以上、線やアイコンは 3:1 以上を目安に選んでいます（WCAG 2.2 AA）。

名前は短い書き方（--panel・--ink のように短く、--color- を付けない）にそろえています。

  • ボタンの variant：primary＝rose、secondary＝gray、negative＝red（削除など）、danger＝orange（注意が必要な操作）、success＝green
  • 通知の色（--tone-*）：info＝blue、warning＝amber、error＝red、success＝green。面はスケールの200

守ること

  • 必ずセマンティックトークンを参照し、プリミティブトークンや Hex を直接指定するのは NG
  • HEX・rgb()・hsl() を :root の外に書かない（check_colors.py が止める）
  • 白地で 4.5:1 を満たす文字色は --ink / --ink-soft。--wine-deep（rose-550）は 4.15:1 で、基準未満を承知のうえでの決定
