画面の骨組み

画面の骨組み・幅・余白の決まりです。部品を並べる前に、どの器（l-wrap）に入れて、どの余白で区切るかを決めます。2列は c-media を使います。

ページの骨組み

決まり

  • ヘッダー（c-header）→ 下層ページの見出し（c-page-head）→ セクション（l-section）→ フッター（c-footer）の順に積む
  • 内容は必ず l-wrap に入れる。画面の端までは広げない（背景色だけは端まで塗ってよい）。l-wrap を入れ子にしない
  • ページの見出しは1画面に1つ（h1）。セクションの見出しは h2
  • セクションの縦の区切りは l-section（96px）。下層ページは l-section--post と併記する
ヘッダー（c-header・--z-sticky）
c-page-head：分類・ページの見出し・リード文
l-section：セクション（l-section__head に見出し）
96px
l-section：セクション

コンテナの幅

クラス内容の最大幅使う画面
l-wrap1180px（--container-lg）・左右 32px（SP 20px）ふつうのページ・一覧
l-wrap l-wrap--narrow760px（--container-md）記事の本文・フォーム・読みもの（1行の文字数を増やしすぎない）
a-main管理画面の本文（管理画面の骨格）管理画面・横に長い表

ブレークポイント

  • ブレークポイントは 980・760・620px の3つ（--bp-lg / --bp-md / --bp-sm）＋ヘッダーだけの 1100px（--bp-header）（ブレークポイント）
  • 620px 以下（スマホ）：1列にする。フォームのボタンは横幅いっぱいにし、上から［前の画面に戻る］［送信する］の順（見た目とキーボードの順番をそろえる）
  • 表は横スクロールにする。列を無理に縮めない
  • カードを並べるときは c-cards（選択肢カード）、それ以外の並びは c-grid（1枚の最小幅 288px。入らない分は自動で折り返す）

余白の決め方

関係の近いものほど近くに、遠いものほど離して置きます（近接の原則）。迷ったら次の表から選び、ほかの値は作りません。

関係余白例
部品の中4px / 8pxアイコンと文字、ラベルと補足説明
同じまとまりの中の項目どうし16px / 24pxフォームの項目どうし（24px）、カードの中の段落
まとまりどうし48pxフォームの見出しごとのまとまり
ページのセクションどうし64px「お知らせ」と「サービス」

まとまりB

項目C・項目D

まとまりの中は近く（8px）、まとまりどうしは遠く（48px）。区切りがひと目で分かる

項目C・項目D

一覧の上のツールバー

  • 検索欄・絞り込み・件数を一覧の上にまとめる（c-toolbar）
  • 検索欄は c-toolbar__grow で残りの幅を使う。ボタンとは同じ高さ（lg）にする
  • 件数は右端に 14px（c-toolbar__count）
