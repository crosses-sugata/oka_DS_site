通知・読み込み

アラート・トースト・読み込み・タグとバッジなど、状態や結果を知らせる部品です。

アラート

色：blue＝情報、amber＝注意（warning）、red＝エラー、green＝success。面の色はどれもスケールの200です。

お知らせ

ダミーテキストA。お知らせの本文が入ります。

確認してください

ダミーテキストB。注意してほしい内容が入ります。

送信できませんでした

入力内容に誤りがあります。赤く表示された項目を確認してください。

完了しました

確認メールをお送りしました。

使う

  • すぐ下にタブ（c-tabs）を置くと、部品が 24px 空ける（画面で余白を書かない）
  • 画面の中に置いたままにする大事なお知らせ（エラーの理由、注意点など）
  • タイトル（16 bold）＋本文（16 regular）

使わない・してはいけない

  • 一時的な結果の通知に使わない（トーストを使う）
  • 1つの画面にたくさん並べない（大事さが伝わらなくなる）

アクセシビリティ

  • すぐ伝えたいエラーは role="alert"、それ以外は role="status"
  • 色だけでなくアイコンと文字で種類を伝える

トースト

操作の結果を短く伝えます。通信エラーなどのエラーは赤系の面で出します。大事な内容（エラーの理由など）はトーストだけで伝えません。

  • 成功・情報：5秒（--toast-duration）で自動で消えます。マウスを乗せている間・フォーカスがある間は消しません
  • エラー：自動では消しません。閉じるボタンで閉じます
  • 読み上げ：成功・情報は role="status"、エラーは role="alert"
  • 操作に失敗したとき（削除できなかったなど）：トーストで短く知らせ、理由と次の操作は画面上部の c-alert--error に残す。このアラートには role を付けない（トーストの role="alert" と合わせて2回読まれないように）
保存しました
通信に失敗しました。もう一度お試しください
複数行になる場合のダミーテキストA。文字が長くて折り返すときも、アイコンと閉じるボタンは1行目の高さにそろえます。

使う

  • 操作の結果を短く伝える（保存しました・コピーしました）
  • 成功・情報は5秒で消える。エラーは閉じるまで残る

使わない・してはいけない

  • 理由の説明や、次にしてほしい操作をトーストだけで伝えない
  • 1度にたくさん出さない

アクセシビリティ

  • 成功・情報は role="status"、エラーは role="alert"
  • マウスを乗せている間・フォーカス中は消えない

JS で出す（js/components.js）

コードを表示コピーしました
<script>
  // 成功・情報：5秒で消える（--toast-duration）／エラー：閉じるまで残る
  OKALC.toast('保存しました', { type: 'success', icon: '（check_circle_fill1 の SVG）' });
  OKALC.toast('通信に失敗しました。もう一度お試しください', { type: 'error' });
</script>

読み込み

ブロック（16 / 20 / 24 / 32px）
色は親の文字色を受け継ぎます
プログレスバー
スケルトン

使う

  • すぐ終わる処理（2秒程度まで）：ブロック
  • 形が決まっている内容を読み込むとき：スケルトン
  • 進み具合が分かるとき：プログレスバー

使わない・してはいけない

  • 画面全体をブロックで覆わない（どこを読み込んでいるか分からなくなる）

アクセシビリティ

  • ブロックだけを置くときは role="status" と aria-label
  • ボタンの中では aria-hidden（ボタンに aria-busy を付ける）
  • 動きを減らす設定の人には、ゆっくり動かす

ラベルセットの中でラベルの右に置くタグです。ほかのタグとは別の部品（c-req）で、使う場所はラベルの横だけです。

タグ・バッジ

標準 おすすめ 情報 進行中 エラー 完了
大きいタグ お知らせ3 新着あり

使う

  • タグ：分類や状態を短い言葉で示す
  • 必須／任意（c-req）：ラベルの横だけ
  • 記事の状態は管理画面の a-status を使う（一覧）

使わない・してはいけない

  • タグをボタンの代わりにしない（押せる見た目にしない）
  • 色だけで意味を伝えない（必ず文字を入れる）

アクセシビリティ

  • 数だけのバッジには、読み上げ用の文字を添える（例：未読 3件）
