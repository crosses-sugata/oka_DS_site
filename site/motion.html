モーション

動きは「何が起きたか」を伝えるために使い、飾りのためには使いません。短く（300ms以内）、同じ種類の動きには同じ時間とイージングを使います。公開サイトの演出（スクロールで現れる・写真の切り替え）だけは例外で、長めの時間を使います。

関連ページデザイントークン

テキストボックスやボタン類の大きさが変わる動きは NG

拡大・縮小（scale）で部品の大きさを変えません。変化は色・透明度・位置で表します。

この端末では「動きを減らす」設定がオンです

そのため見本はほとんど動きません。OS の設定（アクセシビリティ → 視差効果を減らす）をオフにすると確認できます。

公開サイトの動き

動きは控えめに。すべて prefers-reduced-motion: reduce で無効化・即時化する。

種類定義
スクロールリビール.u-reveal → IntersectionObserver で .is-in（js/site.js）
カードホバーtranslateY(-6px) ＋ --shadow ・300ms（--duration-slow）
ボタンホバーtranslateY(-2px) ・200ms（--duration-def）
ヒーロースライダーopacity 1200ms（--duration-fade）・5秒間隔
アコーディオン高さ 300ms

.u-reveal は、js/site.js が動いたとき（html に is-reveal-ready が付いたとき）だけ隠れ、画面に入ると is-in でふわっと出る。js/site.js を読まないページでは最初から表示される。

時間

トークン値動くときのイメージ用途
--duration-instant100ms色の切り替え・押下
--duration-fast150mshover・focus
--duration-def200ms開閉・チェック・スイッチ（標準）

--duration-reveal600ms演出（例外）：スクロールで現れる（u-reveal）
--duration-fade1200ms演出（例外）：ヒーローの写真の切り替え

イージング（動きの速さの変化）

トークン値イメージ用途
--ease-standardcubic-bezier(0.2, 0, 0, 1)画面内での変化
--ease-entercubic-bezier(0, 0, 0, 1)現れる（速く出て、ゆっくり止まる）
--ease-exitcubic-bezier(0.3, 0, 1, 1)消える（ゆっくり動き出して、速く去る）
--ease-linearcubic-bezier(0, 0, 1, 1)回転・読み込み

イージングの比較は、違いが分かるように1秒かけて動かしています。

動きを減らす設定への対応

OS で「視差効果を減らす／アニメーションを減らす」を選んでいる人には、移動・フェードをすべて止め、状態だけを切り替えます。読み込み中の表示だけは、処理中だと分かるように速度を落として残します（prefers-reduced-motion: reduce）。
