アイコン

公開サイトの部品は下の「公開サイトの線のアイコン」を、フォーム・通知などの部品は Material Symbols Rounded（線のみ）を使います。Material Symbols は表示サイズで形を使い分けます：16・20px は太さ500・20px用の形、24・32px は太さ400・24px用の形です。アイコンはインライン SVG に c-icon と、サイズのクラスを付けます。色は親から受け継ぎます。装飾の SVG には aria-hidden="true" を付けます。

公開サイトの線のアイコン

公開サイトの部品は、次の線のアイコンをインライン SVG で使います（viewBox="0 0 24 24"・fill="none"・stroke="currentColor"・線の端は round）。色は親から継承します。装飾の SVG には aria-hidden="true" を付けます。

  • c-icon--arrow（→）／ c-icon--chev（∨）／ c-icon--ext（外部・移動）。インライン SVG に付ける
  • 大きさと線の太さは SVG の属性（width height stroke-width）で決める。部品ごとの値は各部品の見本に合わせる

アイコンルール

  • 形式：SVG
  • 形態：round、stroke（fill は一部で使用）
  • クラス：c-icon ＋ サイズ c-icon--sm / md / lg / xl（部品と同じ c- で始まる名前）
  • サイズ：24px グリッド
  • 線幅：約2px（24・32px は太さ400・24px用の形、16・20px は太さ500・20px用の形。小さく表示しても線が細くなりすぎないようにする）
  • アウトプット：アウトライン化、コンポーネント化
  • レイヤー名：icon/{アイコン名}

使い分け

線（標準） 塗り（通知の種類を示すとき・選択中など、一部だけ） ブランド色（装飾）
