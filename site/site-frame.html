ページの骨格

ページの横幅を決める l-wrap と、縦の区切りの l-section の使い方（HTML とクラス）です。幅やブレークポイントの数値と決まりは レイアウト を見てください。

関連ページレイアウト画面の骨組み共通UI

l-wrap / l-section — 骨格

クラス：l-wrap l-section

HTML

コードを表示コピーしました
<section class="l-section">
  <div class="l-wrap">
    <div class="l-section__head"><h2>項目A</h2></div>
    <p>ダミーテキストA</p>
  </div>
</section>
<article class="l-section l-section--post">
  <div class="l-wrap l-wrap--narrow"><p>ダミーテキストB（記事の本文は narrow で行長を抑える）</p></div>
</article>
クラス役割
l-wrap横幅 1180px・左右 32px（SP 20px）
l-wrap--narrow760px。記事の本文で使う
l-section縦 96px の区切り
l-section--post下層ページ用。上36px・下44px（本文で終わるページは余白を半分にする）
l-section--group上下40px。連続するセクションを一続きに見せる（施設について→アクセス→代表者紹介）
l-section__headセクション見出しの器（下 48px）

使わない・してはいけない

  • ❌ l-wrap を入れ子にしない（左右余白が二重にかかる）
  • ❌ 下層ページで l-section を単体で使わない。必ず l-section--post と併記する

アクセシビリティ

  • 見出しの段を飛ばさない（ページの h1 → セクションの h2）
  • セクションは section 要素にし、見出しと aria-labelledby でつなぐ

l-section__group-heading — 群の中の小見出し

クラス：l-section__group-heading

CSS

コードを表示コピーしました
.l-section__group-heading { /* 明朝19px */ }
.l-section__group-heading::before { content: ""; width: 18px; height: 2px; background: var(--wine); }

「アクセス」「代表者コラム」など、h2 にするほどではない見出し。 左に18×2px のワインのバーが付く。

🔵 h2 に戻さない

施設について〜代表者紹介は一群として余白を詰めている（l-section--group）。 その中の見出しを h2 に上げると、群としてのまとまりが崩れる。

アクセシビリティ

  • 見た目は小見出しでも、前後の見出しの段に合った h 要素にする
  • 飾りの線は疑似要素なので読み上げない
