管理画面

管理画面だけで使う部品（a-）と決まりです。公開サイトと管理画面の両方で使う部品（ボタン・タブ・省略表示など）は共通部品（c-）に置き、管理画面でもそれを使います。トップページ用の部品（p-）は使いません。

関連ページボタンラベル・入力欄通知・読み込みモーダル・ツールチップ囲み・カード・料金・表空状態・区切り

ドロワー（a-topbar / a-scrim / a-side__close）

クラス：a-topbar a-scrim a-side__close

≤980px で a-side は画面外へ隠れる。

CSS

コードを表示コピーしました
@media (max-width: 980px) {
  .a-shell { grid-template-columns: minmax(0, 1fr); grid-template-rows: auto 1fr; }
  .a-side  { position: fixed; width: 280px; transform: translateX(-100%); visibility: hidden; }
  .a-side.is-open { transform: none; visibility: visible; }
}

必要なマークアップ:

クラス役割
a-topbar上の帯。ロゴと開くボタンを載せる
a-topbar__toggle開くボタン。44px角
a-topbar__brand帯の中のロゴ。高さ32px
a-side__close閉じるボタン。ロゴの右上に重ねる
a-scrim背景の覆い。押すと閉じる

  </div>
  <div class="a-scrim" id="drawer-scrim" hidden></div>
  <aside class="a-side" id="a-side">
    <button class="a-side__close" id="drawer-close" type="button" aria-label="メニューを閉じる"><svg class="c-icon c-icon--md" viewBox="0 -960 960 960" aria-hidden="true" focusable="false"><!-- icons/20/close.svg の path --></svg></button>
    <!-- a-side__brand・a-side__nav・a-side__user は上の「a-side — サイドメニュー」と同じ -->
  </aside>
  <main class="a-main" id="a-content"><!-- 本文 --></main>
  <script src="js/components.js" defer></script>   <!-- 共通部品の動き（トースト・検証・省略表示など）。admin.js より先に読む -->
  <script src="js/admin.js" defer></script>
</body>

⚠️ grid-template-rows: auto 1fr を省かない

a-shell は min-height: 100vh のグリッドで、align-content の既定は stretch。 中身が画面より短いと余った高さが各行へ均等配分され、帯が 62px → 187px に膨らむ 。

⚠️ 閉じているあいだは visibility: hidden にする

transform だけだと、隠れていてもタブ移動で中のリンクに到達できてしまう。

⚠️ このマークアップを省かない

a-topbar・a-scrim・a-side__close が無いと、≤980px（タブレット・スマートフォン）ではサイドメニューが画面外に消えたまま開けない。 切り替えもログアウトもできなくなる。開閉の動きは js/admin.js。

⚠️ 開いた直後に focus() しても効かない

admin.css は visibility を --duration-slow（300ms）かけて遷移させる。 クラスを付けた直後はまだ visibility: hidden で、見えない要素にフォーカスは入らない。 transitionend を待ってから移す（タイマーの保険も置く）。

アクセシビリティ

  • メニューボタンは aria-expanded と aria-controls
  • Esc で閉じる（js/admin.js）

一覧

記事・質問を並べる画面。管理画面でいちばん使う。

一覧表 — 共通部品の c-data-table を使う

一覧の表は公開サイトと同じ共通部品の c-data-table（囲み・カード・料金・表）。列幅・長いタイトルの省略・狭い画面での振る舞いもそちらにまとめてある。状態バッジ（a-status）と行の操作（a-ops）は管理画面だけで使う。

記事の一覧（スマホ幅では2列に畳む）

620px 以下では、列名の行を見た目だけ消し（読み上げには残す）、左に内容の列（1行目 タイトル／2行目 状態と日付）、右に操作の列（ゴミ箱のアイコンボタン。中身ぶんの幅）にする。横スクロールも右端の貼り付けもしない。広い画面は今までどおり4列。削除はどの幅でもゴミ箱のアイコンのボタン。画面の幅を狭めると確かめられる。
