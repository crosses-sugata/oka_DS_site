OKA.L.C Design System

人とAIの両方が読んで理解でき、同じ品質のUIを作れることを目指したデザインシステムです。

実装での使い方

次の順で読み込みます。クラスの頭文字は c-（共通の部品）・l-（レイアウト）・p-（トップページ固有）・u-（ユーティリティ）・a-（管理画面）です（命名規則）。各部品の見本の下にある「コードを表示」から、HTML をコピーして使えます。

読み込み

コードを表示コピーしました
<link rel="preconnect" href="https://fonts.googleapis.com">
<link rel="preconnect" href="https://fonts.gstatic.com" crossorigin>
<link rel="stylesheet" href="https://fonts.googleapis.com/css2?family=Shippori+Mincho:wght@400;500;700&family=Zen+Kaku+Gothic+New:wght@400;500;700&family=Outfit:wght@400;500;600&display=swap">  <!-- 書体（3種・使う太さだけ） -->
<link rel="stylesheet" href="tokens/tokens.css">       <!-- トークン（CSS 変数） -->
<link rel="stylesheet" href="css/base.css">           <!-- フォント・リセット・アイコン・フォーカス -->
<link rel="stylesheet" href="css/components.css">     <!-- 部品（c- / l- / p- / u-） -->
<link rel="stylesheet" href="css/admin.css">          <!-- 管理画面だけ（a-） -->
<link rel="stylesheet" href="css/tool.css">           <!-- 院内ツールだけ（t-）。admin.css の代わりに読む -->
<script src="js/components.js" defer></script>        <!-- セレクト・タブ・モーダル・トーストなどの動き -->
<script src="js/site.js" defer></script>              <!-- 公開サイト：ヘッダー・メニュー・目次・アコーディオン・スライド・u-reveal -->
<script src="js/admin.js" defer></script>             <!-- 管理画面だけ：ダイアログ・ドロワー・トースト -->
  • アイコンは icons/（24・32px 用）と icons/20/（16・20px 用）の SVG の中身を、<svg class="c-icon c-icon--md" viewBox="0 -960 960 960" aria-hidden="true"> の中に入れて使います
  • あとから画面に足した部品は OKALC.init(要素) で動くようにします（渡した要素の中にある部品が対象。要素そのものは対象外なので、親を渡す）。トーストは OKALC.toast('保存しました')
  • エラー文・トーストのアイコンは、JS が自分では持っていません。ページに SVG を置き、読み込んだあとで OKALC.errorIcon（項目の下のエラー文）・OKALC.closeIcon（トーストの閉じる）に入れ、トーストには icon で渡します（下の例）
  • サイトで状態を見せるための is-hover などのクラスは、実装では付けません（:hover などで自動で変わります）

アイコンの入れ方（エラー文・トースト）

コードを表示コピーしました
<template id="tpl-icon-close"><!-- icons/20/close.svg の中身を c-icon の svg で --></template>
<template id="tpl-icon-error"><!-- icons/20/error_fill1.svg --></template>
<template id="tpl-icon-success"><!-- icons/20/check_circle_fill1.svg --></template>
<script>
  document.addEventListener('DOMContentLoaded', () => {
    const tpl = (id) => document.getElementById(id)?.innerHTML ?? '';
    OKALC.closeIcon = tpl('tpl-icon-close');   // トーストの閉じるボタン
    OKALC.errorIcon = tpl('tpl-icon-error');   // 項目の下のエラー文（c-formset__error）
    // 完了を知らせる：OKALC.toast('送信しました', { type: 'success', icon: tpl('tpl-icon-success') });
  });
</script>

ファイル

tokens/tokens.jsonトークンの正本（DTCG形式：デザイントークンの標準的な書き方）
tokens/tokens.css上から自動生成される CSS 変数（直接編集しない）
css/base.cssフォント・リセット・文字・アイコン・フォーカス・モーション共通
css/components.css部品（c- / l- / p- / u-）
css/admin.css管理画面の部品（a-）
css/tool.css院内ツールの部品（t-）
js/components.js部品の動き（依存なし）
js/site.js / js/admin.js公開サイトの動き／管理画面の動き
icons/Material Symbols Rounded の SVG（24・32px 用は太さ400、icons/20/ の16・20px 用は太さ500）
書体Shippori Mincho（見出し）・Zen Kaku Gothic New（本文・UI）・Outfit（数字・英字）。Google Fonts から各ページの <head> で読む
DESIGN.md / AGENTS.md / llms.txtAI が最初に読むファイル（DESIGN.md は自動生成）
docs/部品ごとの仕様（md・json）・トークン・ガイドライン（自動生成）
scripts/check_colors.py色の直書き・プリミティブの直接使用を見つける検査
scripts/check_rules.pyクラス名・余白（4の倍数）・ブレークポイント・JS が探す ID・ボタンの組み合わせの検査
scripts/build.pyトークンとサイトを作るスクリプト（python3 scripts/build.py）
