一覧・記事・よくある質問

関連ページ公開サイト管理画面

お知らせ／コラム／よくある質問はPHPの動的出力（公開サイトのテンプレート）。 サービス案内はPythonの静的生成（サービス案内のページを作るスクリプト）。同じクラスを両方が出力する。

c-post-list — 記事の一覧

クラス：c-post-list

見本

  • 2026.08.01 ダミーテキストA
コードを表示コピーしました
<ul class="c-post-list__items c-post-list__items--wide c-post-list" data-step="10">
  <li><a class="c-post-list__item" href="#" aria-disabled="true">
    <time class="c-post-list__date" datetime="2026-08-01">2026.08.01</time>
    <span class="c-post-list__title">ダミーテキストA</span>
  </a></li>
</ul>
<div class="c-post-list__more-wrap">
  <button class="c-button c-button--pill c-button--ghost c-post-list__more" type="button" hidden>もっと見る</button>
</div>
  • 初回10件 ＋「もっと見る」で10件ずつ（data-step="10"）。JSが hidden を外していく
  • 全件表示済み・10件未満のときはボタンごと消える。余白はボタン側に持たせているので下に隙間が残らない
  • お知らせは日付、コラムは No.（総件数から逆算）を c-post-list__date に入れる
  • c-post-list__link は見出し右端の「一覧はこちら」

使わない・してはいけない

  • ❌ 「全○件」を出さない（依頼者指示で削除済み）
  • ❌ 記事URLを日付やスラッグ形式に変えない。記事ID形式のまま（合意事項）

アクセシビリティ

  • 日付は time と datetime。リンクの名前は記事のタイトル
  • 「もっと見る」で増えた最初の記事へフォーカスが移る（js/site.js）

c-post — 記事の詳細

クラス：c-post

HTML

コードを表示コピーしました
<article class="l-section l-section--post">
  <div class="l-wrap l-wrap--narrow">
    <div class="c-post__head">
      <time class="c-post__meta" datetime="2026-08-05">2026.08.05</time>
      <h1 class="c-post__title">記事タイトル</h1>
    </div>
    <div class="c-post__body">
      <p>ダミーテキストA</p>
    </div>
    <div class="c-post__foot">
      <a class="c-post__back" href="#">← お知らせ一覧へ戻る</a>
    </div>
    <nav class="c-post-nav" aria-label="記事ナビゲーション">
      <a class="c-post-nav__link" href="#">
        <span class="c-post-nav__cap">次の記事</span>
        <time class="c-post-nav__meta" datetime="2026-08-10">2026.08.10</time>
        <span class="c-post-nav__title">項目A</span></a>
      <a class="c-post-nav__link c-post-nav__link--next" href="#">
        <span class="c-post-nav__cap">前の記事</span>
        <time class="c-post-nav__meta" datetime="2026-07-24">2026.07.24</time>
        <span class="c-post-nav__title">項目B</span></a>
    </nav>
  </div>
</article>
クラス中身
c-post__head日付（c-post__meta）＋タイトル（c-post__title serif 28px / SP 24px）
c-post__body本文 15.5px / 行間2.05。strong mark a figure img にスタイルあり
c-post__foot本文の下の行。記事は「← 一覧へ戻る」（c-post__back）、エラーページは主ボタン（下の「エラーページ」）
c-post-nav前後記事。2カラム、SPは1カラム。タイトルは2行で省略
  • mark は背景を消してワインの太字にしている（蛍光ペンにしない）
  • 本文の a は下線つき（記事内はリンクが目立つほうがよい）

アクセシビリティ

  • 記事の見出しは h1
  • 前後の記事は nav aria-label="記事ナビゲーション"
  • 本文の画像に alt

エラーページ（404）

クラス：c-post の部品を使う（専用の部品は持たない）

ページが見つからないときの画面。ヘッダーはロゴだけにして、ナビゲーションとメニューのボタンは出さない（迷わせない）。本文は記事の詳細と同じ組み方で、本文の下の行（c-post__foot）に「トップページへ戻る」をピル型の主ボタンで1つだけ置く。2026-10-04 追加（ユーザーの指示）。

見本

ページが見つかりません

お探しのページは移動または削除された可能性があります。

トップページへ戻る
コードを表示コピーしました
<section class="l-section l-section--post">
  <div class="l-wrap l-wrap--narrow">
    <h1 class="c-post__title">ページが見つかりません</h1>
    <div class="c-post__body">
      <p>お探しのページは移動または削除された可能性があります。</p>
    </div>
    <div class="c-post__foot"><a class="c-button c-button--pill" href="#">トップページへ戻る</a></div>
  </div>
</section>
  • ボタンを c-post__body の中に置かない。本文のリンクの決まり（文字色・下線）がボタンにも効き、文字が背景と同じ色になる
  • ボタンはピル型（c-button c-button--pill）。公開サイトの導線のボタンと同じ形にする
  • HTTP の状態は 404 で返す（200 で返すと、検索エンジンに正常なページと伝わる）。canonical は出さない。noindex
  • ヘッダーにメニューのボタンを出さないので、js/site.js の nav-toggle / mobile-nav は無くてよい（site-header は要る）

c-faq — よくある質問

クラス：c-faq

見本

施設について

Q ダミーテキストA

ダミーテキストB

コードを表示コピーしました
<section class="c-faq">
  <div class="c-faq__group" id="group-a">
    <h2>施設について</h2>
    <details class="c-faq__item" id="q1">
      <summary>
        <span class="c-faq__q">Q</span>
        <span class="c-faq__q-text">ダミーテキストA</span>
        <svg class="c-icon--chev" width="16" height="16" viewBox="0 0 24 24" fill="none" stroke="currentColor" stroke-width="2.4" stroke-linecap="round" stroke-linejoin="round" aria-hidden="true"><path d="m6 9 6 6 6-6"/></svg>
      </summary>
      <div class="c-faq__a"><p>ダミーテキストB</p></div>
    </details>
  </div>
</section>
  • <details> / <summary> を使う。JSでの開閉を実装しない（JS無効でも開ける）
  • 開くと c-icon--chev が180度回る
  • 回答の画像は max-width: 320px。原寸より拡大しない
  • カテゴリのジャンプリンクはサービス案内と同じ c-toc。地色が --bg-soft なので --toc-bg を差し替える

使わない・してはいけない

  • ❌ トップページのFAQを絞り込まない。15問すべて表示のままで確定
  • ❌ 回答の文章をサービス案内の表記ルールに揃えない。公式サイトの原文ママが正しい状態 （「下さい」「殆ど」「御相談」などが残っているのは揃え忘れではない）

アクセシビリティ

  • details / summary で開閉するので JS が無くても動く
  • Q 番号は文字として読まれる。開閉の矢印は aria-hidden

c-post-nav — 前後の記事

HTML

コードを表示コピーしました
<nav class="c-post-nav" aria-label="記事ナビゲーション">
  <a class="c-post-nav__link" href="…">
    <span class="c-post-nav__cap">次の記事</span>
    <time class="c-post-nav__meta" datetime="2026-08-10">2026.08.10</time>
    <span class="c-post-nav__title">記事タイトル</span></a>
  <a class="c-post-nav__link c-post-nav__link--next" href="…">
    <span class="c-post-nav__cap">前の記事</span>
    <time class="c-post-nav__meta" datetime="2026-07-24">2026.07.24</time>
    <span class="c-post-nav__title">記事タイトル</span></a>
</nav>
クラス役割
c-post-nav2列のグリッド（1fr 1fr）。≤620px で1列
c-post-nav__linkカード1枚。白地＋枠線。ホバーで --wine-tint
c-post-nav__link--nextgrid-column: 2 ＋ 右寄せ。 古い記事（「前の記事」）に付く
c-post-nav__cap「次の記事」「前の記事」。12px / 600 / --ink-soft
c-post-nav__meta日付・No.。--num 14px / --wine-deep
c-post-nav__titleタイトル。2行で省略（-webkit-line-clamp: 2）

⚠️ クラス名と表示ラベルが逆に見える

--next が付くほうが古い記事（「前の記事」）。 --next は「次の記事」の意味ではなく、グリッドの2列目という意味。

⚠️ 片方しか無いときは、その <a> だけを出す

両方無ければ <nav> ごと出さない。 前後のナビは公開済み記事だけを辿る（下書き・予約中はスキップ）。
