ラベル・入力欄

ラベルセット・テキストフィールド・テキストエリア・セレクトなど、入力の部品です。

関連ページチェック・ラジオ・スイッチフォームの組み方管理画面

ラベルセット

ラベルセット ＝ ラベル ＋ 必須/任意タグ ＋ 補足説明 ＋ 入力例 ＋ フォームパーツ ＋ エラーテキスト

入力例は「例：」で始めます（「入力例：」とは書きません。→ ライティング）。

間の余白は 4px と 8px だけで組みます：文字どうし（ラベル・補足説明・入力例）は 4px、文字とフォームパーツの間は 8px、フォームパーツとエラーテキストの間は 4px。フォームパーツは c-formset__control で包みます。

必須

ダミーテキストA（補足説明）

例：hanako@example.com

メールアドレスの形式で入力してください

任意

ダミーテキストB（補足説明）

0 / 256

ラベルの大きさ

ラベル 16px（--font-def） ラベル 14px（--font-sm）

使う

  • 入力欄・セレクト・テキストエリア・選択肢は、必ずラベルセットで包む
  • 必須か任意かをタグで示す。すべての項目にラベルと必須／任意を付ける（チェックボックス1つだけの項目＝同意なども同じ）
  • チェックボックス・ラジオはラベル1つ：選択肢が複数（1:n）。項目のラベルは fieldset.c-formset の legend.c-formset__head、選択肢の文字は各 c-choice の中
  • 入力例は「例：」で始める
  • エラーは入力欄のすぐ下に、何が起きたか＋どうすればよいかを書く

使わない・してはいけない

  • プレースホルダーをラベルの代わりにしない
  • エラーを赤い枠だけで伝えない（必ず文字とアイコンを添える）
  • 補足説明・入力例・エラーを 4px / 8px 以外の余白で組まない

アクセシビリティ

  • label の for と入力欄の id をつなぐ
  • 補足説明・入力例・エラーの id を aria-describedby でつなぐ
  • エラーのときは aria-invalid="true"
  • 選択肢のまとまりは fieldset ＋ legend で組む

サイズ

横に並べるときのルール

入力欄とボタンを横に並べるときは、高さを必ずそろえる

同じサイズ名（例：入力欄 lg と ボタン lg）どうしを並べます。違う高さのものを並べるのは NG です（デザインハーネスで検査します）。

使う

  • 既定の高さは 48px（c-field）。ボタンと並べるときは同じサイズ名にそろえる
  • 単位や記号は c-field__affix で箱の中の前後に置く
  • 箱の中にボタンを置くときは c-field__action（箱より 8px 低くなる）

使わない・してはいけない

  • 入力欄とボタンを違う高さで並べない（例：入力欄 lg ＋ ボタン md）
  • affix の中に大事な説明を書かない（補足説明に書く）

アクセシビリティ

  • 箱の中のアイコンボタンには aria-label
  • hover で枠が 2px、フォーカスで 2px の枠が外側に出る（大きさは変わらない）
  • 入力欄の枠は白地と 3.4:1

複数行（テキストエリア）

既定の高さは3行分です。入力に合わせて高さが伸びます（autogrow）。最大文字数（maxlength）を決めたときだけ、箱の中の右下に「0 / 256」を出します。最大文字数が無いときは表示しません。

上限を超えても入力は止めません。超えた文字の背景が赤くなり、文字数も赤で出ます。直さずに送信すると、フォームのエラー（「256文字以内で入力してください（3文字多い）」）で止めます。

enable（最大文字数あり）
0 / 256
enable（最大文字数なし）
hover
0 / 256
focus
3 / 256
error（上限を超えた・送信した後）
15 / 12
disabled

使う

  • 既定は3行分。入力に合わせて高さが伸びる
  • 最大文字数があるときだけ maxlength を付ける（右下に文字数が出る）
  • 上限を超えても打てる。超えた文字の背景が赤くなり、送信時にエラーで止める（js/components.js が maxlength を外して見張る。JS が動かないときは maxlength がそのまま効く）

使わない・してはいけない

  • 最大文字数が無いのに文字数を出さない
  • resize（手で大きさを変える）を付けない

アクセシビリティ

  • 文字数は1文字ごとには読み上げない（aria-live を付けない）。上限を超えたとき・戻ったときだけ JS が知らせる
  • 超えたことは赤い背景だけでなく、文字数（15 / 12）と送信時のエラー文でも伝える
  • 文字数の要素の id を aria-describedby でつなぐ

使う

  • 選択肢が 5〜15 個程度のとき
  • 一覧の1行は 40px。長い項目は折り返して全文を出す
  • 選択肢が多く、種類で分けられるときはグループ分け（c-menu__group）にする
  • フォームで送るときは、中に <input type="hidden" class="c-select__input" name="…"> を置く。選んだ値（項目の data-value、無ければ文字）が入る。必須は data-required（送信時・欄を離れたときに「〇〇を選択してください」）

使わない・してはいけない

  • 選択肢が 2〜4 個ならラジオボタンにする（一度に見える方が選びやすい）
  • 選択肢が多すぎる（数十個以上）ときは検索付きの部品にする

アクセシビリティ

  • ↑↓ で移動、Enter で決定、Esc で閉じる、文字を打つとその文字で始まる項目へ移動
  • role="combobox" ＋ role="listbox" / "option"、選択中は aria-selected
  • グループは role="group" と aria-labelledby で見出しにつなぐ。見出しは選択肢として読まない
  • JS：js/components.js（data-select を付けると動く）
