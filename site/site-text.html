見出しと文章のブロック

見出しの3段・本文のまとまり・箇条書きなど、文章を組む部品です。

関連ページ文字ライティング公開サイト

見出しの3段

見本

項目A（セクションの見出し）

ダミーテキストA（セクション冒頭の要約）

項目B（小見出し）

ダミーテキストB

項目C（囲みの中の小見出し）

  • ダミーテキストC
  • ダミーテキストD
コードを表示コピーしました
<section class="c-section-block" id="oc" aria-labelledby="oc-title">
  <h3 class="c-section-block__title" id="oc-title">項目A（セクションの見出し）</h3>
  <div class="c-text">
    <p class="c-lead">ダミーテキストA（セクション冒頭の要約）</p>
    <h4 class="c-subtitle">項目B（小見出し）</h4>
    <p>ダミーテキストB</p>
    <div class="c-checklist">
      <p class="c-block-title">項目C（囲みの中の小見出し）</p>
      <ul class="c-list" role="list"><li>ダミーテキストC</li><li>ダミーテキストD</li></ul>
    </div>
  </div>
</section>
クラスpx書体使う場所目次
c-section-block__title21serifページ内のセクション見出し。左にワインのバー載る
c-subtitle18sansセクション内の小見出し載らない
c-block-title16sans囲みの中の小見出し（チェックリスト／料金表／箇条書き）載らない

データの書き方（サービス案内のデータ）

JSON

コードを表示コピーしました
{ "type": "h3", "text": "効果の目安", "sub": "初回のみ" }
  • セクション（c-section-block）は sections[]、小見出しは {"type": "h3"}
  • sub は見出しの後ろに小さく添える補足。（ ）は自動で付き、目次には出ない

使う

  • 見出しは短く。条件や但し書きは sub に逃がす
  • id と aria-labelledby を必ず対にする（目次のジャンプ先になるため）

使わない・してはいけない

  • ❌ 見出しを話し言葉にしない。 「どのくらい効果があるの？」→「効果の目安」
  • ❌ c-block-title を囲みの外で使わない（囲みの中の見出しという意味が壊れる）
  • ❌ 番号付きステップ（steps）は廃止済み。 復活させない。順序に意味がある場合は 見出しテキストに 1. 2. を書く（手順の説明がこの形）

アクセシビリティ

  • h2 → h3 → h4 の段を飛ばさない
  • c-subtitle__note は見出しの一部として読まれるので短くする

⚠️ c-block-title は .svc-box-title / .svc-list-title / .svc-price-title の3つを統合したもの 。3つとも15px太字で、違いは下マージンだけだった。再び分けない。

c-subtitle__note — 見出しに添える補足

クラス：c-subtitle__note

見本

項目Aの流れ（所要30分程度）

コードを表示コピーしました
<h3 class="c-subtitle">項目Aの流れ<span class="c-subtitle__note">（所要30分程度）</span></h3>

CSS

コードを表示コピーしました
.c-subtitle__note { font-family: var(--sans); font-size: var(--font-def); font-weight: 400; color: var(--ink-soft); }

見出し自体は短いままにして、条件や但し書きだけをこちらに逃がす。

  • 書体は明朝ではなくゴシック。太さも400に戻す（見出しの一部に見せない）
  • 目次には出ない（c-toc は見出しのテキストを拾うが、注記は補足として読ませる）

使わない・してはいけない

  • 見出しそのものを長くして条件を書き込む
  • ここに本文を書く（長い補足は c-note）

c-text — 本文のまとまり

クラス：c-text

見本

セクション冒頭の要約（16px）

本文（14px）

太字にして立てる一文

必ず目に留めてほしい一文（濃いピンク＋太字）

※ 2行目以降が1文字分下がる

コードを表示コピーしました
<div class="c-text">
  <p class="c-lead">セクション冒頭の要約（16px）</p>
  <p>本文（14px）</p>
  <p class="c-text--strong">太字にして立てる一文</p>
  <p class="c-text--strong c-text--accent">必ず目に留めてほしい一文（濃いピンク＋太字）</p>
  <p class="c-text--hang">※ 2行目以降が1文字分下がる</p>
</div>
クラス効果
c-text中の要素に16pxの間隔を入れる器。本文14px
c-lead16px・やや太い。セクションの冒頭に1つだけ
c-text--strong太字。{"type":"p","bold":true}
c-text--accent濃いピンク（--primary-solid）。必ず目に留めてほしい一文だけに使い、c-text--strong と組み合わせる（色だけに頼らない）
c-text--hangぶら下げインデント。※ で始まる段落にレンダラが自動で付ける

使う

  • 「※」は段落の先頭に置き、半角スペースを1つ空ける（※ 〜）
  • 注記は本文と同じ14px。区別は色（本文＝--ink ／ 注記＝--ink-soft）が担う

使わない・してはいけない

  • ❌ c-text--hang をデータ側で指定しない（自動判定される。二重指定は無意味）
  • ❌ 本文のサイズを個別に変えない。変えるときは c-text / c-list li / c-price__label / c-card__desc の4つを揃える

アクセシビリティ

  • 段落は p、強調は strong
  • 余白を作るために br を重ねない

c-list — 箇条書き

クラス：c-list

見本

  • 項目A
  • 項目B
  • 項目C
  • 項目A
  • 項目B
  • 項目C
  • 項目D
コードを表示コピーしました
<ul class="c-list" role="list"><li>項目A</li><li>項目B</li><li>項目C</li></ul>
<ul class="c-list c-list--grid" role="list"><li>項目A</li><li>項目B</li><li>項目C</li><li>項目D</li></ul>   <!-- 2〜3列に並べる -->
  • 行頭はピンクの丸だけ（--blush 6px）。c-list--grid は180px以上で自動的に列数が決まる（SPは2列）
  • 箇条書きの文末に句点を付けない。 段落には付ける

使わない・してはいけない

  • ❌ c-checklist の中でだけ別の記号を使わない（中身は普通の c-list）

アクセシビリティ

  • ul / ol を使う
  • CSS で行頭の記号を消しているので role="list" を付ける（Safari の読み上げがリストと扱わないことがあるため）

⚠️ CSSの順序に依存がある。c-list li::before（丸）を打ち消すルールは必ずその後ろに置く。 順序を入れ替えると記号が丸に戻る。

c-indent — 1段下げる

クラス：c-indent

見本

1. 項目A

ダミーテキストA（番号付きの見出しに続く本文を1段下げる）

コードを表示コピーしました
<div class="c-text">
  <p>1. 項目A</p>
  <div class="c-indent"><p>ダミーテキストA（番号付きの見出しに続く本文を1段下げる）</p></div>
</div>

番号付きの見出しに続く本文などを 20px（SP 12px）下げる。データ側は "indent": true を 任意のブロックに付けられる。

アクセシビリティ

  • 字下げは見た目だけ。手順などの構造は ol や見出しで表す

文章のルール（サービス案内のみ）

⚠️ このルールが及ぶのは サービス案内のデータ だけ。 よくある質問・お知らせ・コラムは公式サイトの原文ママが正しい状態で、表記を揃えない。

ルール
ひらがなにするください／いただく／ため／など／とくに／および
使わない下さい／頂く／為／等／特に／及び
句読点・記号全角の「、。」のみ。半角の ,.!?・三点リーダ・半角括弧は使わない。範囲は 〜（U+301C）
伝聞「〜と聞きます」「〜ようです」→ 「〜とされています」
敬語「おられる」→「いる」
使わない語いろいろ／かなり／やはり／分かりやすく言えば
箇条書きの文末句点を付けない

例外: 「こんなときにご相談ください」「こんなお悩みはありませんか？」は残す。 利用者への呼びかけとして意図的に置いているもの（依頼者確認済み）。
