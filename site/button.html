ボタン

ボタンは c-button 1つです。角型（既定）は画面の操作に使い、色・形・大きさを修飾子で変えます。ピル型（c-button--pill）は公開サイトの導線（予約など）に使うイレギュラーなボタンです。

関連ページ共通UIフォームの組み方ライティング
使う場面書き方見た目
画面でいちばん大事な操作（送信する・保存する）c-button（c-button--primary と書いてもよい）角型・rose-600 の塗り・高さ 48px
ほかの操作（やめる・削除する など）c-button ＋ 色・形・大きさの修飾子角型

ピル型（公開サイトの導線）

クラス見た目
c-button--pillワインの塗り＋影。CTA
c-button--pill c-button--ghost枠線だけ。「もっと見る」など
  • 角丸は 999px（完全な丸）。サイズ違いは作らない
  • 入力欄と横に並べない（高さ約56px。横に並べるボタンは角型を使う）
  • ラベルは white-space: nowrap。折り返させない。 幅が足りないときは周りを詰める （禁止パターン の「ボタンやバッジのラベルを折り返させない」）
  • ≤980px ではヘッダー内のボタンを隠す（c-header__cta .c-button）

角型（画面の操作）

角丸 --radius-control・高さはサイズ表・hover は色だけ変わります。

--btn-xl
--btn-lg
--btn-md
--btn-sm
  • アイコンはボタンの左右に入る可能性がある、アイコンとテキストの間4px（--gap-1）
  • variant：primary / secondary / negative / danger / success。それぞれに対して solid / outline / subtle / ghost のパターンあり
  • state：enable / hover / focus / loading / disabled
トークン高さパディングフォントアイコン
--btn-xl5612/242024
--btn-lg4812/241620
--btn-md408/161620
--btn-sm324/121416

既定のサイズは lg（48px）で、入力欄と同じ高さです。

使う

  • 画面でいちばん大事な操作に primary の solid を1つだけ使う
  • ほかの操作は secondary、または outline / ghost で強さを下げる
  • 取り消せない操作（削除など）は negative、注意が必要な操作は danger
  • アイコンは左右どちらにも置ける。アイコンと文字の間は 4px（自動）

使わない・してはいけない

  • 1つの画面に primary の solid を2つ以上並べない
  • 色・形・大きさの修飾子のボタン（画面の操作用）をリンク（ページを移動する）に使わない。ページへの導線（予約など）は c-button--pill
  • 文字の無いボタンを aria-label なしで置かない
  • 押したときに大きさを変える動きを付けない（色だけ変える）
  • 入力欄と並べるときに違う高さのサイズを混ぜない

アクセシビリティ

  • Tab で移動、Enter / Space で押せる（button 要素を使えば自動）
  • アイコンだけのボタンは aria-label で名前を付ける
  • 読み込み中は aria-busy="true"、押せないときは disabled
  • 色の修飾子（primary〜success の solid）の白文字×地色は 4.5:1 以上（danger は 4.51:1）。c-button--pill（--wine の塗り）は 3.25:1 で、基準未満を承知のうえでのブランドの決定

variant色使うとき

secondarygrayprimary の次に大事な操作。やめる・閉じるなど目立たせない操作にも使う
negativered削除など、取り消せない操作
