院内ツール

院内ツール（いまは紹介状 作成ツール）だけで使う部品（t-）と決まりです。ボタン・一覧表・メニューの一覧・モーダル・トースト・通知は共通部品（c-）をそのまま使い、t- にはほかに置き場の無いものだけを置きます。公開サイトの部品（p-）と管理画面の部品（a-）は使いません。2026-11-03 追加。

関連ページ管理画面ボタン囲み・カード・料金・表モーダル・ツールチップ通知・読み込みタブ・リンク・ページ送り

決まり

  • 院外へ通信しない。Web フォント（Google Fonts）も読まない。書体は --sans の指定のまま、先頭の書体が無い端末では OS のゴシックで表示する（2026-11-03 決定）
  • CSS は tokens/tokens.css → css/base.css → css/components.css → css/tool.css の順に読む。css/admin.css は読まない
  • 確認は共通の c-modal（js/admin.js の OkaDialog）。ブラウザの alert / confirm は使わない（2026-11-03 決定）。閉じる前の確認（beforeunload）だけはブラウザが出すもので、文言を変えられない
  • 操作の結果は共通の c-toast（OKALC.toast）。位置・消えるまでの時間は共通の決まりのまま（2026-11-03 決定）
  • 紙の上の色は --tool-* のトークンだけを使う。紙に刷る字と印（○・✓）は、原本と同じ黒で描く（画面の色ではなく、印刷物の中身）

骨格

画面全体・ヘッダー・⋮ の操作メニュー。

t-shell — 画面全体

クラス：t-shell

実装では <body class="t-shell"> に付ける。見出しはゴシック（毎日使う業務画面なので、管理画面と同じく読みやすさを優先する）。

t-screen — 一覧と入力の切り替え

クラス：t-screen t-screen--fill

一覧と入力は同じページの2つの画面。別のページにしない（フォントや郵便番号の表を抱えていて、開くのに数秒かかるため）。見せない画面は hidden。入力の画面は t-screen--fill で窓の高さいっぱいに使い、紙の部分だけを送る。

t-head — 3列のヘッダー

クラス：t-head t-head__side t-head__side--end t-head__brand t-head__logo t-head__name t-head__ver t-head__format

t-range — 作成日の範囲

クラス：t-range t-range__label t-filter

「作成日　[から] 〜 [まで]」の1かたまり。c-toolbar の中に置く。日付の入力欄は共通の c-field（type="date"）。片方だけ入れてもよい。病院名などの選ぶ絞り込み（共通の c-select）は t-filter で包んで幅を決める。

t-sort — 列名で並べ替える

クラス：t-sort

列名をボタンにする。今の並びは th の aria-sort が持つ（ascending / descending / none）。矢印は上向きが昇順、並べていない列は薄く出す。同じ列をもう一度押すと逆順。

アクセシビリティ

  • 並びの状態は th の aria-sort で伝える（ボタンの文字には足さない）

t-pick — 様式を選ぶ一覧

t-edit — 紙の上の入力欄

クラス：t-edit t-edit__at t-edit__at--choice t-edit__at--off t-edit__at--warn t-edit__box t-edit__box--lines t-edit__mark t-edit__menu t-edit__menubtn

  • 入力欄の字は透明。紙に見える字は SVG が描く（入力欄に字を描かせると、折り返しや書体の違いで刷り上がりとずれる）。カーソルが紙の字と同じ位置に来るよう、書体・大きさ・行送り・ベースラインを紙に合わせる
  • 位置は ％、文字の大きさは --k（紙の 1pt が画面の何 px か）に掛ける。拡大しても紙にくっついたまま動く
  • 打てる場所は、手を乗せたときだけ枠で示す
  • 選ぶ欄（○・☑）は、紙の印の上に押しどころ（t-edit__mark）を重ねる。印は紙が描く
  • 選ぶものが決まっている文字の欄は、右端に ▼（t-edit__menubtn）を添え、一覧は共通の c-menu。選んでも紙に出るのはただの文字
  • 直したい欄は枠の色だけ変える（t-edit__at--warn）。文言は欄の下に出さず、紙の右横の欄（t-side）にまとめる（欄の下に出すと並びが動く）

アクセシビリティ

  • 入力欄には aria-label で欄の名前を付ける（紙のラベルは SVG の中で読み上げられない）
  • Tab の順は紙の上から下、同じ高さ（6pt 以内）なら左から右。DOM に足す順番がそのまま Tab の順
  • 選ぶ欄の押しどころは aria-pressed で選んだかを伝える

印刷 — 紙だけを原寸で刷る

「印刷する」は画面の紙をそのまま刷る（window.print()）。css/tool.css の @page と @media print が、紙以外（ヘッダー・帯・入力欄・目印・右横の欄・トースト）を消し、余白 0 の A4 に 210mm × 297mm で置く。

  • 入れ物の高さが 1px でも積み上がると、白紙の2ページ目が出る。紙の周りの入れ物は余白・高さを 0 にして数えさせない
  • 2枚組は1枚＝1ページで続けて刷る。最後の紙のあとで改ページしない
  • 印刷まわりを直したら、印刷用の CSS を当てた状態で文書の高さが「297mm × 枚数」ちょうどか、はみ出す要素が無いかを測る

t-side — 紙の右横の欄

クラス：t-side t-side__list t-side__go
