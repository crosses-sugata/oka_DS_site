タブ・リンク・ページ送り

パンくず（c-breadcrumb）は公開サイト用の部品に置き換えました。ページの器と共通UI を見てください。

関連ページ共通UI

タブ

クリックか、左右の矢印キーで切り替えられます。

ダミーテキストA
ダミーテキストB
ダミーテキストC

state

enable hover focus selected disabled

使う

  • 同じ画面の中で、同じ種類の内容を切り替える（2〜6個）

使わない・してはいけない

  • ページの移動にタブを使わない（リンク・ナビゲーションを使う）
  • タブの中にさらにタブを入れない

アクセシビリティ

  • Tab でタブの列へ、←→ で切り替え、HomeEnd で端へ
  • role="tablist" / "tab" / "tabpanel"、aria-selected・aria-controls
  • JS：js/components.js（role="tablist" があると動く）

リンク

アクセス hover focus 外部サイト

使う

  • ページを移動するとき（色は --wine-deep、下線あり）

使わない・してはいけない

  • 下線を消さない（色だけでリンクと分からせない）
  • 「こちら」「詳しくはここ」をリンクの文字にしない
  • 操作（送信・削除など）にリンクを使わない（ボタンを使う）

アクセシビリティ

  • 新しいタブで開くリンクは、そのことを文字（アイコンの aria-label）で伝える
  • 文字と背景の比は 5.4:1

スマホ・狭い場所：今のページ／全ページ

state

  • enable
  • hover
  • focus
  • current
  • disabled

使う

  • 一覧が1ページに入り切らないとき
  • 件数を添えると、全体の量が分かる

使わない・してはいけない

  • ボタンを9個より多く並べない（「…」で省く）
  • 今のページをリンクのままにしない

アクセシビリティ

  • nav ＋ aria-label="ページ送り" で囲む
  • 今のページは aria-current="page"、前後の矢印は aria-label で名前を付ける
